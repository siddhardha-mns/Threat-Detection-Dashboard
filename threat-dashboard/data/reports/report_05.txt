Following lateral movement onto domain controllers, an adversary leveraged process hollowing to inject unauthorized DLLs into svchost.exe. The injected shellcode subsequently executed OS credential dumping against LSASS memory to harvest Kerberos ticket-granting tickets and NTLM password hashes. Staged artifacts on disk exhibited SHA1 hash da39a3ee5e6b4b0d3255bfef95601890afd80709 and connected to command node 192.0.2.99.
